# Промпт: реалізація однієї задачі

---

Реалізуй TASK-<номер> у репозиторії цього продукту. Спершу прочитай AGENTS.md, README.md, docs/STATE.md і опис задачі. Перевір G3 для цієї хвилі, baseline і залежності. Прочитай пов’язані REQ/NFR, AC, UX, ADR та активні модулі.

Підсумуй очікувану поведінку, межі й перевірки. Якщо є блокер або суперечність, назви конкретні ID й потрібне рішення; не змінюй scope мовчки. За відсутності блокерів виконай задачу автономно в погоджених межах, не запитуючи повторного дозволу на кожний локальний крок.

Збережи чужі зміни. Виконай релевантні тести та збірку, ручні перевірки згідно з TEST. Не заявляй успіх без доказу. Онови статус задачі, докази й стан передачі. Не публікуй продукт і не виконуй руйнівних дій без відповідного доручення.

У відповіді: результат, змінені файли, покриті AC, виконані перевірки, невиконані перевірки з причинами, відомі ризики. Якщо done не досягнуто — чесно залиш review або blocked.
