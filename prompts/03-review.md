# Промпт: узгодженість і готовність

---

Перевір поточний продукт за guide/TRACEABILITY.md. Ціль перевірки: <G1/G2/G3/G4 або TASK-ID>. Прочитай джерела істини та пов’язані докази; не редагуй вимоги лише для того, щоб перевірка пройшла.

Перевір: повноту головного шляху, scope, AC, NFR, UX-стани, дані, активні модулі, унікальність визначень ID, реальність посилань, залежності без циклів, відсутність задач поза scope і відповідність доказів заявленому статусу. Для G3 перевір planned-тести і ready-задачі; для G4 — результати всіх Must цього випуску.

Виведи знахідки у форматі severity / ID / файл / суперечність / виправлення / власник. Відокрем блокери від неблокуючих зауважень. Для кожного невідомого вкажи, що саме не перевірено. За відсутності знахідок назви межі перевірки й докази; не роби загального висновку про безпеку всього продукту.

Запропонуй pass, conditional або fail, але не запиши людське погодження від мого імені. Збережи результат перевірки у docs/evidence/ і додай посилання до STATE, якщо доступний запис файлів.
